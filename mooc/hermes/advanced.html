🚀 进阶使用

多平台接入、自动化任务与高级配置

多平台接入（Gateway）

Hermes 最强大的功能之一是多平台网关（Gateway）——同一个 AI 智能体可以同时接入 10+ 个聊天平台：

平台说明配置难度
Telegram通过 Bot API 接入，最常用⭐⭐
Discord需要创建 Discord 应用⭐⭐
企业微信国内用户首选⭐⭐⭐
飞书企业协作平台⭐⭐⭐
钉钉阿里系协作平台⭐⭐⭐
Slack国际企业协作⭐⭐
WhatsApp国际即时通讯⭐⭐⭐
邮件通过邮件与 Hermes 交互⭐⭐

配置网关

$ hermes gateway setup # 交互式配置平台 $ hermes gateway run # 前台运行（测试用） $ hermes gateway install # 安装为后台服务
📱 配置完成后，你可以在手机上通过微信/Telegram 直接与 Hermes 对话，它拥有和在终端中完全一样的能力——执行命令、操作文件、搜索网页。

Telegram 配置示例

1

在 Telegram 中搜索 @BotFather，发送 /newbot 创建机器人，获取 Token

2

在 ~/.hermes/.env 中添加：
TELEGRAM_BOT_TOKEN=你的Token

3

运行 hermes gateway setup，选择 Telegram 并完成配置

WebUI 部署

除了终端和聊天平台，Hermes 还有一个社区维护的 Web 界面（Hermes WebUI），可以通过浏览器使用。

Docker 一键部署

docker pull ghcr.io/nesquena/hermes-webui:latest docker run -d --name hermes-webui -e WANTED_UID=$(id -u) -e WANTED_GID=$(id -g) -v ~/.hermes:/home/hermeswebui/.hermes -v /www:/workspace -p 8787:8787 --restart always ghcr.io/nesquena/hermes-webui:latest

部署后访问 http://你的服务器IP:8787 即可使用。

🔒 安全提醒：部署到公网时务必设置密码！在启动命令中添加 -e HERMES_WEBUI_PASSWORD=你的密码，或部署后在设置页面设置。

开放防火墙端口

$ ufw allow 8787/tcp

定时任务

Hermes 内置了 Cron 定时任务系统，可以让 AI 在指定时间自动执行任务。

创建定时任务

$ hermes cron create "每天早上8点检查服务器状态并发送报告" $ hermes cron create "每小时抓取一次新闻摘要" --schedule "0 * * * *"

管理定时任务

命令作用
hermes cron list列出所有定时任务
hermes cron pause ID暂停任务
hermes cron resume ID恢复任务
hermes cron run ID立即执行一次
hermes cron remove ID删除任务
🤖 定时任务让 Hermes 变成一个真正的"数字员工"。你可以让它定时备份数据、监控网站状态、抓取行情数据等。

多智能体协作

Hermes 支持启动多个智能体实例，让它们并行工作或分工协作。

使用 delegate_task 分配子任务

在对话中，Hermes 可以自动将复杂任务拆分成子任务并行处理：

# 在 Hermes 对话中这样说： 帮我同时做三件事： 1. 检查 /www/wwwroot/ 下所有网站的磁盘占用 2. 查看最近 24 小时的系统日志 3. 更新所有 git 仓库

Hermes 会自动启动 3 个子智能体并行处理。

使用 tmux 启动独立实例

# 启动一个独立的后端开发智能体 tmux new-session -d -s backend -x 120 -y 40 'hermes -w' # 启动一个独立的前端开发智能体 tmux new-session -d -s frontend -x 120 -y 40 'hermes -w'
⚡ -w 参数启用 worktree 模式，让多个智能体在独立的 Git 工作区中操作，避免代码冲突。

进阶配置技巧

配置文件结构

~/.hermes/ ├── config.yaml # 主配置文件（设置、模型、工具等） ├── .env # API 密钥和敏感信息 ├── skills/ # 已安装的技能 ├── sessions/ # 会话记录 └── logs/ # 网关和错误日志

常用配置命令

$ hermes config edit # 在编辑器中打开配置 $ hermes config set agent.max_turns 50 # 调整最大对话轮次 $ hermes config check # 检查配置完整性 $ hermes tools # 交互式管理工具集

多配置档案（Profiles）

如果你需要在不同场景使用不同配置（比如工作用一套、个人用一套），可以创建配置档案：

$ hermes profile create work # 创建工作档案 $ hermes profile create personal # 创建个人档案 $ hermes --profile work # 使用工作档案启动
