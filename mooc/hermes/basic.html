🎮 基础使用

掌握日常对话、模型切换和核心命令

开始对话

最简单的启动方式——直接输入 hermes：

$ hermes

进入交互式聊天模式，可以自然对话，Hermes 会实时回复。它不仅仅是聊天机器人，更能执行终端命令、读写文件、搜索网页。

单次提问模式

$ hermes chat -q "如何在 Ubuntu 上安装 Docker？" $ hermes chat -q "用 Python 写一个文件备份脚本"

切换模型

Hermes 支持随时切换 AI 模型：

$ hermes model

使用方向键选择，回车确认。在对话中也可用 /model 临时切换。

常用模型推荐

模型特点适用场景
deepseek-chat速度快、成本低日常对话、简单任务
deepseek-reasoner深度推理代码调试、逻辑分析
claude-sonnet-4代码能力出色编程、代码审查
gpt-4o综合能力强复杂任务、创意工作

常用斜杠命令

在对话中输入 / 开头的命令执行操作：

会话管理

命令作用
/new 或 /reset开始新会话
/clear清屏并开始新会话
/title 名称给会话命名
/resume 名称恢复之前命名的会话
/compress压缩上下文（对话太长时）
/undo撤销上一次对话

配置与工具

命令作用
/model查看或切换模型
/config查看当前配置
/tools管理工具集
/skills浏览和安装技能
/skill 技能名加载指定技能
/help查看所有命令

实用工具

命令作用
/yolo跳过危险命令确认（谨慎）
/stop停止后台进程
/history查看对话历史
/save保存对话到文件
/quit退出
🎯 不必记住所有命令——输入 /help 查看完整列表。大多数时候只需自然对话。

技能系统入门

技能（Skills）是 Hermes 最独特的功能——就像给 AI 安装"专业技能包"。

浏览和安装

$ hermes skills browse # 浏览技能市场 $ hermes skills install php-website-development $ hermes skills install docker-compose-deployment

技能有两种使用方式：

  1. 自动触发：提到相关任务时自动加载
  2. 手动加载：对话中输入 /skill 技能名
🧠 技能让 Hermes "记住"你的工作流程。比如安装 docker-compose-deployment 技能后，每次部署 Docker 项目都自动遵守你的偏好设置。

会话管理

Hermes 自动保存每个会话：

$ hermes sessions list # 列出最近会话 $ hermes sessions browse # 交互式浏览 $ hermes --continue # 继续最近会话 $ hermes --resume ID # 恢复指定会话

会话文件保存在 ~/.hermes/sessions/。
