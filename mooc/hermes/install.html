📥 安装部署

从零开始，在你的电脑上安装 Hermes Agent

系统要求

项目最低要求推荐配置
操作系统Linux / macOS / WSL2Ubuntu 22.04+ / macOS 14+
Python3.10+3.11 或 3.12
内存2 GB4 GB+
磁盘空间1 GB5 GB+
网络稳定互联网连接低延迟（API 调用更快）
💡 Windows 用户注意：Hermes Agent 原生支持 Linux/macOS。Windows 用户需要先安装 WSL2（Windows Subsystem for Linux），在 PowerShell 中运行 wsl --install 即可。
⚠️ 本文以 Linux 服务器（Ubuntu）为例进行演示。macOS 用户的安装步骤几乎相同，只需将 apt 替换为 brew。

一键安装

Hermes Agent 提供了官方安装脚本，一行命令即可完成安装：

curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
📝 安装脚本会自动：① 创建 ~/.hermes/ 配置目录；② 克隆源码；③ 安装 Python 依赖；④ 创建 hermes 命令快捷方式。

安装过程大约需要 2-5 分钟。完成后你会看到：

# 安装成功后的输出 ✅ Hermes Agent installed successfully! Run 'hermes' to start chatting. Run 'hermes setup' to configure.

配置 API 密钥

Hermes Agent 需要连接大语言模型（LLM）服务商来获得 AI 能力。推荐使用 DeepSeek（国内用户首选）或 OpenRouter。

方式一：DeepSeek（推荐，性价比高）

1

访问 DeepSeek 开放平台，注册并创建 API Key。

2

编辑环境配置文件：

nano ~/.hermes/.env
3

添加以下内容（替换为你的真实密钥）：

DEEPSEEK_API_KEY=sk-your-api-key-here
4

运行配置向导选择 DeepSeek：

$ hermes setup model

在交互界面中选择 DeepSeek，推荐模型 deepseek-chat。

方式二：OpenRouter（模型选择最多）

在 ~/.hermes/.env 中添加 OPENROUTER_API_KEY，然后运行 hermes setup model 选择 OpenRouter。

支持的模型服务商

服务商配置变量适用场景

💰 DeepSeek 价格约 ¥1/百万 token，个人用户每月花费通常在几元到几十元之间。

验证安装

$ hermes doctor

正常输出示例：

# hermes doctor 输出 ✅ Python 3.12.3 ✅ config.yaml found ✅ .env file found ⚠️ git not found (optional)
🎉 看到绿色的 ✅ 就说明安装成功！试试第一条命令：hermes chat -q "用中文说一句问候语"
