🖥️ 认识 Photoshop

界面布局、文件操作与视图控制

工作界面总览

打开 Photoshop 后，你会看到以下核心区域：

区域位置功能
菜单栏顶部文件、编辑、图像、图层、滤镜等所有功能入口
选项栏菜单栏下方显示当前选中工具的详细参数和选项
工具栏左侧移动、选区、画笔、文字等所有工具（可按 Tab 隐藏）
面板区右侧图层、颜色、调整、历史记录等面板组合
画布区中央编辑图像的主工作区域
💡 点击菜单栏 窗口 → 工作区 → 复位基本功能 可以随时恢复默认布局。

新建、打开与保存文件

新建文件

快捷键 Ctrl + N (Mac: ⌘ + N)

🎯 常用预设：Web 图片用 1920×1080px/72dpi，印刷品用 A4/300dpi，头像用 800×800px/72dpi。颜色模式默认 RGB 即可。

打开文件

快捷键 Ctrl + O，或直接将图片拖入 PS 窗口。支持 JPG、PNG、PSD、TIFF、GIF 等常见格式。

保存文件

操作快捷键说明
保存Ctrl + S覆盖原文件，保持格式
另存为Ctrl + Shift + S选择新格式/新位置
导出为Ctrl + Alt + Shift + W精细控制导出质量（推荐 Web 用）
存储为 Web 所用格式Ctrl + Alt + Shift + S经典导出方式，可预览文件大小
⚠️ PSD 是 Photoshop 源文件格式，保留所有图层和编辑信息。如果要发到网上，记得导出为 JPG 或 PNG。

视图操作

操作快捷键
放大Ctrl + + 或 Alt + 滚轮上
缩小Ctrl + - 或 Alt + 滚轮下
适合屏幕Ctrl + 0
100% 实际大小Ctrl + 1
抓手平移按住 空格键 + 鼠标拖动
旋转视图（PS CC 2019+）按 R 键 + 拖动
🖱️ 高效技巧：按住 Alt 滚动滚轮 = 缩放；按住 空格 拖动 = 平移。这是最常用的两个视图操作。

撤销与历史记录

  • 撤销一步：Ctrl + Z（再次按可恢复）
  • 撤销多步：Ctrl + Alt + Z 连续按可逐步后退
  • 历史记录面板：窗口 → 历史记录，可跳转到任意历史状态

  • ✅ 学会高效的视图缩放和平移操作
  • ✅ 了解了撤销和历史记录的使用
