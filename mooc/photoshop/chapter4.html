🎨 调色与滤镜

掌握色彩调整与滤镜特效

调整图层——非破坏性调色

点击图层面板底部的创建新的填充或调整图层按钮（半黑半白圆形图标），选择调整类型。调整图层的好处是随时可以修改参数、随时可以删除，不会永久改变原图。

最常用的四种调整

调整快捷键（直接调整）作用
亮度/对比度—最简单明暗调节，适合快速微调
色阶Ctrl + L精准控制暗部、中间调、亮部
曲线Ctrl + M最强大的调色工具，可调对比度和色调
色相/饱和度Ctrl + U改变颜色倾向和鲜艳度

色阶与曲线详解

色阶（Ctrl + L）

色阶直方图从左到右代表暗部→亮部。三个三角滑块：

  • 黑色三角（左）：向右拖动让暗部更暗，增加对比度
  • 灰色三角（中）：调节中间调亮度
  • 白色三角（右）：向左拖动让亮部更亮

曲线（Ctrl + M）

曲线是最灵活的调色工具。对角线左下=暗部、右上=亮部：

  • S 形曲线：上提亮部 + 下压暗部 = 增强对比度（最经典用法）
  • 上提中间：整体提亮
  • 下压中间：整体压暗
  • 锚点：单击曲线添加控制点，精确调节特定亮度范围
🎯 人像修图口诀：曲线做 S 形增强对比，色相饱和度降一点点红色让皮肤更通透。

色彩调整

色相/饱和度（Ctrl + U）

  • 色相：改变颜色（如把红色变成蓝色）
  • 饱和度：颜色的浓淡程度（-100 变黑白，+100 极度鲜艳）
  • 明度：颜色的明暗

高级用法：在"全图"下拉菜单中选择特定颜色（如红色），只调整图片中该颜色的色相/饱和度。

色彩平衡（Ctrl + B）

分别调节阴影、中间调、高光中的青色/红色、洋红/绿色、黄色/蓝色比例，适合校正偏色照片。

黑白（Ctrl + Alt + Shift + B）

将彩色图像转为黑白，并可以单独调节每种颜色在黑白中的明暗程度。

常用滤镜

菜单栏 滤镜 → 滤镜库 包含大量预设效果。

滤镜位置用途
高斯模糊滤镜 → 模糊 → 高斯模糊柔化图像，常用于背景虚化、磨皮
USM 锐化滤镜 → 锐化 → USM 锐化增强边缘清晰度，出图前必做
添加杂色滤镜 → 杂色 → 添加杂色增加颗粒感，复古/胶片效果
液化滤镜 → 液化 (Ctrl+Shift+X)推拉变形，常用于瘦脸瘦身
Camera Raw 滤镜滤镜 → Camera Raw 滤镜专业级调色，类似 Lightroom
🧠 智能滤镜：先将图层右键转为智能对象，再添加滤镜。这样滤镜会变成可随时修改参数、随时删除的"智能滤镜"，实现非破坏性编辑。

  • ✅ 能使用色相/饱和度和色彩平衡调整色彩
