🏆 实战案例

综合案例：海报、修图、批量处理、创意合成

综合运用前五章所学

本章通过四个实战案例，将前面学到的图层、选区、文字、调色、抠图等技能串联起来，让你学完就能做出实际作品。

案例一：电商促销海报

目标：制作一张 800×1200px 的手机促销海报

步骤拆解

1

创建画布：Ctrl + N，800×1200px，72dpi，RGB。

2

背景：用渐变工具（G）拉一个从深蓝到浅蓝的径向渐变。或用矩形工具画一个纯色底，添加杂色增加质感。

3

产品图：拖入产品照片，用快速选择工具抠图，添加投影（双击图层→图层样式→投影）。

4

文字排版：用文字工具添加标题（大号加粗）、价格（红色大号）、卖点（较小字号）。用 Ctrl + T 调整位置和大小。

5

装饰元素：用形状工具绘制标签、价格框、按钮等。给文字和形状添加描边或渐变叠加效果。

6

导出：Ctrl + Alt + Shift + S 存储为 Web 所用格式，选 JPG 高品质（80-90%）。

📱 涉及技能：新建文件 → 渐变/形状 → 抠图 → 图层样式 → 文字工具 → 导出，覆盖了前五章大部分知识点。

案例二：人像快速修图

目标：将一张普通照片调整为精致的人像照

1

基础调光：添加曲线调整图层，做轻微 S 形曲线增强对比。添加色阶调整图层，拖白色三角向左提亮整体。

2

肤色优化：添加色相/饱和度调整图层，选"红色"，降饱和度 5-10，提明度 3-5，皮肤更通透。

3

皮肤磨皮：Ctrl + J 复制图层 → 滤镜 → 模糊 → 高斯模糊（半径 3-5）→ 添加黑色蒙版 → 用白色柔边画笔在皮肤区域涂抹。

4

锐化出图：Ctrl + Alt + Shift + E 盖印所有图层到新图层 → 滤镜 → 锐化 → USM 锐化（数量 50-80%，半径 1-2）。

⚠️ 磨皮要适度，保留皮肤纹理才自然。高斯模糊 + 蒙版的方法比"美颜滤镜"效果更真实。

案例三：图片批量处理

目标：将 50 张产品图统一调整为 800×800 正方形，加水印

使用"动作"功能批量处理，事半功倍：

1

打开一张图 → 窗口 → 动作 → 点击"创建新动作"按钮 → 命名"批量处理"→ 开始记录

2

执行操作：图像 → 图像大小 → 800×800 → 添加文字水印 → 存储为 JPG → 关闭文件 → 停止录制

3

文件 → 自动 → 批处理 → 选择刚录制的动作 → 选择源文件夹和目标文件夹 → 确定。PS 自动处理全部照片！

⚡ 动作批处理是效率神器。任何需要重复 N 次的操作都可以录成动作，一键批量处理。

案例四：创意双重曝光

目标：制作人物剪影内嵌风景的双重曝光效果（海报常用技法）

1

打开人物照片，用快速选择工具选中人物 → Ctrl + J 复制到新图层

2

给人物图层添加白色颜色叠加（图层样式），创建纯白剪影

3

拖入风景图放在人物上方 → Ctrl + Alt + G 创建剪贴蒙版，风景只在人物内显示

4

风景图层混合模式设为正片叠底 → 添加图层蒙版，用柔边画笔擦除边缘做渐变过渡

5

在下方添加纯色或渐变背景，完成高级感双重曝光效果

学习路径建议

学完本教程后，你可以按照以下路径继续进阶：

  1. 巩固基础：把六个章节的快捷键背熟，每天打开 PS 练习 30 分钟
  2. 临摹作品：在花瓣网、站酷等平台找喜欢的作品临摹
  3. 专项突破：根据兴趣深入学习（电商设计 / 人像修图 / UI 设计 / 插画）
  4. 建立素材库：收集常用笔刷、字体、纹理、样机模板
  5. 接单实践：在猪八戒、闲鱼等平台接小单积累实战经验
🏆 Photoshop 学习没有捷径，但有方法——每天练习 30 分钟，坚持一个月，超过 90% 的初学者。配合本教程边学边练，效果最佳。
