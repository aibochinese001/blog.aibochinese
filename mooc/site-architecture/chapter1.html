网站是什么 — 输入一个网址后发生了什么

从浏览器地址栏到网页显示，背后隐藏着一整套精密协作的系统

🔗 拆解一个网址

当你在浏览器输入 https://blog.aibochinese.com/mooc 并按下回车时，看起来只是一瞬间的事。实际上，这个动作触发了至少 6 个步骤：

步骤发生了什么类比
1. 解析 URL浏览器拆出协议(https)、域名(blog.aibochinese.com)、路径(/mooc)拆信封：看收件人和信纸页码
2. DNS 查询把域名翻译成 IP 地址（如 144.34.182.184）查电话本：把名字翻译成电话号码
3. 建立连接浏览器与服务器三次握手，建立 TCP 连接拨通电话，确认对方在线
4. SSL/TLS 加密验证证书，协商加密密钥，建立安全通道约定暗号，后面对话只有你们俩懂
5. 发送 HTTP 请求"GET /mooc HTTP/1.1" — 请求网页内容说"请把第3页给我"
6. 服务器响应返回 HTML/CSS/JS 代码，浏览器渲染成页面收到信，展开阅读

🌍 DNS：互联网的电话簿

DNS（Domain Name System）是互联网最重要的基础设施之一。没有 DNS，你只能记住 144.34.182.184 这样的数字地址——想想看多可怕。

💡
关键认知：域名 ≠ 网站。域名只是一个「名字」，指向某台服务器的 IP 地址。你可以有域名没网站，也可以换服务器但保留域名。

DNS 是分层的：

  • 根域名服务器：全球 13 组，知道所有顶级域（.com、.org、.cn）在哪
  • 顶级域服务器：知道 blog.aibochinese.com 的「.com」部分归谁管
  • 权威 DNS：最终返回 blog.aibochinese.com → 144.34.182.184

DNS 查询通常只需要 几十毫秒，因为结果会被层层缓存——你的浏览器、操作系统、路由器、ISP 都会缓存 DNS 记录。

💻 服务器到底是什么？

服务器（Server）本质上就是一台一直开着的电脑，安装了专门用来响应网络请求的软件。它可能是一台物理机器放在数据中心，也可能是一个云上的虚拟机，甚至是一个 Docker 容器。

一台服务器可以同时运行多个网站，由 Web 服务器软件（如 Nginx、Apache）根据域名来区分请求应该交给哪个网站处理——这叫「虚拟主机」。

⚠️
常见误区：买了服务器 ≠ 网站上线。还需要：安装 Web 服务器软件 → 上传网站文件 → 配置域名解析 → 配置 SSL 证书。AI 可以帮你自动完成这 4 步。
