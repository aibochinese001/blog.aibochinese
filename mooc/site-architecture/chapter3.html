数据库与存储 — 网站的记忆系统

用户数据、文章内容、图片文件都存哪里？一文理解数据库、缓存、CDN

🗄️ 数据库：网站的「大脑记忆」

如果前端是脸，后端是大脑，那数据库就是记忆。没有数据库，用户注册的信息、你发布的文章——关掉网页就全没了。

最常用的数据库是 MySQL（开源免费）和 PostgreSQL。数据以「表」的形式存储，每张表就像一个 Excel 表格：

users 表
id: 1, name: "张三", email: "zhang@example.com", registered_at: "2026-01-15"
id: 2, name: "李四", email: "li@example.com", registered_at: "2026-03-20"

后端通过 SQL 语言来操作数据库：

SELECT name, email FROM users WHERE registered_at > '2026-01-01';
🤖
AI 能做什么：告诉 AI「我需要设计一个博客的数据库，有文章表、用户表、评论表」——AI 会生成完整的建表语句。

⚡ Redis：网站的「短期记忆」（缓存）

Redis 是一种内存数据库，速度极快（微秒级），用来存储：

  • 热门数据：首页文章列表（每小时查一次数据库就够了）
  • 用户会话：「你已登录」这个状态，不需要每次都查 MySQL
  • 计数器：文章阅读量、点赞数（高频更新的数据）
  • 任务队列：发送邮件、处理图片等异步任务
⚡
加了 Redis 缓存后，页面加载速度可能从 500ms 降到 5ms——100倍的提升！

📁 文件存储与 CDN

数据库存文字，图片、视频、PDF 则存在文件系统或对象存储中（如阿里云 OSS、AWS S3）。

CDN（内容分发网络）把网站的静态文件（图片、CSS、JS）复制到全球各地的节点服务器上。北京的用户从北京节点下载，纽约的用户从纽约节点下载——速度快了不止一倍。

爱博·客使用 Cloudflare CDN，所以图片 URL 是 cf.aibochinese.com——这就是 CDN 加速后的地址。
