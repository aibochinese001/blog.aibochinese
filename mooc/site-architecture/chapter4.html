服务器与部署 — 让网站跑起来

Linux/宝塔面板/Nginx/Docker — 从代码到上线的完整流程

🐧 Linux：服务器的操作系统

大多数网站服务器运行 Linux（而不是 Windows）。Linux 没有图形界面，所有操作通过命令行完成。但在 AI 时代，你不需要亲自敲命令——告诉 AI 你要做什么，它会帮你执行。

主流的 Linux 发行版：Ubuntu（最流行）、CentOS（企业用）、Debian（稳定）。

⚠️
不要被「命令行」吓到。在 AI 时代，你只是把命令「转述」给 AI。你：『帮我把网站文件上传到服务器』→ AI：执行 scp/rsync 命令。

🏗️ 宝塔面板：服务器的控制台

宝塔面板（BT Panel）是在 Linux 上的一个可视化控制台，让你通过网页来管理服务器：一键安装 Nginx、MySQL、PHP、Redis；可视化创建网站、绑定域名；一键申请和续期 SSL 证书（Let's Encrypt）；文件管理器、数据库管理器（phpMyAdmin）；防火墙、定时任务、日志查看。

爱博·客的所有网站都通过宝塔面板管理。对非技术用户来说，宝塔就是你和服务器之间的翻译官。

🌐 Nginx：网站的守门人

Nginx（发音 "Engine-X"）是世界上最流行的 Web 服务器软件。它的工作是：

  • 接收请求：所有用户访问先到 Nginx
  • 分发请求：静态文件（图片/CSS）直接返回；动态请求转发给 PHP/Python 后端
  • 反向代理：一个域名可以代理到不同后端服务
  • 负载均衡：流量大时，分发到多台服务器
  • SSL 终结：处理 HTTPS 加密解密
🤖
AI 能做什么：「帮我在 Nginx 配置里给 blog.aibochinese.com 添加一个反向代理，把 /api 路径转发到本地的 3000 端口」——AI 会直接修改配置文件并重载 Nginx。

🐳 Docker：网站的打包盒

Docker 把应用和它需要的所有依赖「打包」成一个标准化的容器。好处是：环境一致、一键部署、应用隔离。爱博·客服务器上运行着多个 Docker 容器：Hermes Agent、OpenClaw 数字员工、SearXNG 搜索引擎等等。

🔒 SSL/HTTPS：给网站加一把锁

HTTPS 就是在 HTTP 外面加了一层 SSL/TLS 加密。浏览器地址栏显示的小锁图标，表示你和服务器之间的通信是加密的。

以前 SSL 证书很贵（每年几百美元），现在 Let's Encrypt 提供免费证书，宝塔面板一键就能申请和自动续期。

🔐
没有 HTTPS 的网站在 Chrome 里会显示「不安全」，严重影响用户信任。用宝塔面板 + Let's Encrypt，5 分钟搞定。
