中国大陆 Google AdSense 美国税务信息（W-8BEN）填写完整教程

2025年最新版
正确填写后，美国来源收入预扣税率可降至 0%（AdSense广告）/ 10%（YouTube版税），否则默认最高 30% 被扣！

一、为什么必须填写美国税务信息？

  • Google 是美国公司，必须遵守美国税法（第1441条）
  • 只要有美国流量（美国用户点击/观看），就涉及美国来源收入
  • 中美税收协定生效，中国居民可享受减免税率
  • 不填写 = 自动扣 30%，每月20日前未提交还会暂停付款

二、准备工作（务必提前确认）

项目要求
姓名必须与 AdSense 收款人姓名完全一致（建议用护照拼音）
地址必须与 AdSense 验证地址一致（已收到 PIN 码的地址）
外国 TIN使用中国身份证号码（18位数字），不要留空
无需 ITIN中国大陆居民不需要申请美国纳税人识别号

三、详细填写步骤（7大步全部截图级说明）

1. 登录并进入税务信息页面

  1. 打开 adsense.google.com
  2. 左侧菜单 → 付款（Payments）
  3. 点击 付款信息（Payments info） → 管理设置
  4. 找到「美国税务信息」→ 点击右侧铅笔图标 ✏️

2. 开始填写 W-8BEN 表格

  1. 点击「管理税务信息」
  2. 账户类型：选择 个人（Individual）
  3. 是否美国公民/居民：选择 否
  4. 系统推荐 W-8BEN → 点击开始填写

3. W-8BEN 七步详细填写（最重点）

每一步都必须准确，否则会被拒绝！
  1. 第1步：纳税身份
    姓名：Wei Zhang（与收款人完全一致，首字母大写）
    国家：China
    外国TIN：输入18位身份证号码（例如 110101199001011234）
  2. 第2步：地址
    国家：China
    邮编、省、市、详细地址全部用英文填写
    示例：Room 1203, Building 5, No.88 Beijing Road, Haidian District, Beijing
  3. 第3步：申请税收协定（最关键！）
    是否申请税收协定优惠 → 是
    条约国家 → China
    请勾选以下所有适用项目（多选）：
    • 服务（Services）→ 税率 0%（AdSense 广告收入）
    • 其他版权版税（Other royalties）→ 税率 10%（YouTube 观看收入）
  4. 第4步：预览 PDF → 仔细检查所有信息，无误后继续
  5. 第5步：电子签名 → 输入姓名作为签名
  6. 第6步：美国活动宣誓 → 选择「否，我不在美国提供服务」
  7. 第7步：提交 → 完成！

4. 提交后查看结果

  • 返回「美国税务信息」页面
  • 状态显示 Approved 且税率显示 0%/10% 即成功
  • 如显示 Declined，查看邮件提示重新提交
常见拒绝原因：
1. 姓名与收款人不一致
2. 身份证号码填写错误或留空
3. 没有勾选税收协定
4. 地址与 AdSense 验证地址不一致

四、常见问题解答

问题答案
AdSense 和 YouTube 要分别填吗？不用，共用同一份 W-8BEN
税率是按全部收入扣吗？不是，只对美国来源收入扣税（通常占总收入10%-30%）
企业账户怎么办？选择 W-8BEN-E，TIN 填写统一社会信用代码
多久有效？提交当年 + 之后3个日历年，之后需重新提交
新加坡税务信息也要填吗？要另外填，但与美国税务信息互不影响
