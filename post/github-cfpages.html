GitHub Desktop 同步与 Cloudflare Pages 自动部署

完整的操作指南和视频教程

GitHub Desktop 同步云端

  1. 安装 GitHub Desktop

    访问 GitHub Desktop 官网 下载并安装适用于您操作系统的版本。

  2. 登录 GitHub 账户

    打开 GitHub Desktop，使用您的 GitHub 账户登录。如果没有账户，请先在 GitHub 上注册。

  3. 克隆远程仓库

    点击 "File" → "Clone repository"，选择您要同步的远程仓库，然后点击 "Clone"。

  4. 创建或修改文件

    在本地仓库中创建新文件或修改现有文件。您可以在 GitHub Desktop 中直接编辑，也可以使用其他编辑器。

  5. 提交更改

    在 GitHub Desktop 左侧面板中，您会看到已修改的文件。填写摘要和描述，然后点击 "Commit to main"（或您当前的分支）。

  6. 推送到云端

    点击右上角的 "Push origin" 按钮，将本地更改推送到 GitHub 云端仓库。

  7. 同步云端更改

    如果云端有其他人推送的更改，点击 "Fetch origin" 获取最新更改，然后点击 "Pull origin" 合并到本地。

注意：确保网络连接稳定，推送和拉取操作可能需要一些时间，具体取决于文件大小和网络速度。

GitHub 连接 Cloudflare Pages 自动部署

  1. 登录 Cloudflare Dashboard

    访问 Cloudflare Dashboard 并使用您的账户登录。

  2. 进入 Pages 设置

    在左侧导航栏中找到 "Pages" 选项并点击进入。

  3. 创建新项目

    点击 "Create a project" 按钮，然后选择 "Connect to Git"。

  4. 连接 GitHub 账户

    选择 GitHub 作为 Git 提供商，然后授权 Cloudflare 访问您的 GitHub 账户。

  5. 选择仓库

    从列表中选择您要部署的 GitHub 仓库。

  6. 配置构建设置

    根据您的项目类型设置：

    • 构建命令：例如 npm run build 或 gatsby build
    • 构建输出目录：例如 build 或 public

  7. 环境变量（可选）

    如果您的项目需要环境变量，在此步骤中添加。

  8. 部署

    点击 "Save and Deploy" 开始首次部署。

  9. 自动部署

    之后每次向连接的分支推送代码时，Cloudflare Pages 都会自动触发新的构建和部署。

提示：您可以自定义域名、设置预览分支、配置重定向规则等高级功能。
