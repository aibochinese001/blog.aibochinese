四、端口放行与防火墙配置

基础防火墙操作

在后续使用中，如需放行端口或禁止防火墙，可执行以下代码：

🔸 端口放行与防火墙管理
# 放行指定端口（示例：22117）
iptables -I INPUT -p tcp --dport 22117 -j ACCEPT

# 停止防火墙服务
systemctl stop firewalld.service

# 禁用防火墙开机自启
systemctl disable firewalld.service

iptables 无效时的解决方案

如果iptables指令无效，请尝试以下步骤：

🔹 Ubuntu/Debian 系统修复
# 启动iptables服务
sudo systemctl start iptables

# 更新软件包并安装iptables
sudo apt update
sudo apt install -y iptables

# 检查PATH环境变量（针对root用户）
echo $PATH

# 若缺失/usr/sbin，临时添加路径
export PATH=$PATH:/usr/sbin

使用 UFW 防火墙（推荐）

UFW是Ubuntu/Debian系统的轻量级防火墙工具，操作更简便：

🔹 安装并配置 UFW
# 安装ufw（轻量防火墙工具）
sudo apt install -y ufw

# 开放信令端口（TCP）
sudo ufw allow 22116/tcp

# 开放中继端口（UDP）
sudo ufw allow 22117/udp

# 重启ufw使配置生效
sudo ufw reload
