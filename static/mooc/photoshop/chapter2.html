📐 图层与选区

掌握图层系统和选区操作

图层是什么

图层是 Photoshop 最核心的概念。想象一下：每个图层就像一张透明的玻璃纸，你可以在上面画画、放图片，所有图层叠在一起就形成了最终的图像。

图层之间互不影响——修改一个图层不会破坏其他图层的内容。这就是非破坏性编辑的基础。

图层面板操作

操作方法
新建图层面板底部 按钮，或 Ctrl + Shift + N
复制图层拖到新建按钮，或 Ctrl + J
删除图层拖到垃圾桶图标，或按 Delete
显示/隐藏点击图层左侧眼睛图标
锁定图层点击面板上方锁定图标
调整顺序直接上下拖动图层
合并图层Ctrl + E 合并选中图层

图层类型

类型图标特征说明
普通图层空白缩略图最基本的图层，可以绘制和编辑
背景图层带锁图标新建文件默认带锁，双击可解锁转为普通图层
文字图层T 图标可随时编辑文字内容、字体、大小
形状图层色块缩略图矢量图形，无损缩放
调整图层半白半黑圆形非破坏性调色，下方所有图层受影响
智能对象右下角小图标保护原始图像，可反复缩放不失真
💡 黄金法则：养成使用 Ctrl + J 复制图层再编辑的习惯。万一改坏了，原图层还在。

选区工具

选区就是告诉 Photoshop「我只想编辑这一块区域」。创建选区后，所有操作只对选区内的内容生效。

基本选区工具

工具快捷键用途
矩形选框M创建矩形/正方形选区
椭圆选框Shift + M创建椭圆/正圆选区
套索工具L自由手绘选区
多边形套索Shift + L点击创建直线边选区
磁性套索Shift + L自动吸附边缘的套索

选区常用操作

操作快捷键
取消选区Ctrl + D
反向选区Ctrl + Shift + I
全选Ctrl + A
羽化（柔化边缘）Shift + F6
加选（按住 Shift 再选）累加多个选区
减选（按住 Alt 再选）从选区中减去

变换与对齐

选中图层后按 Ctrl + T 进入自由变换，你可以：

  • 缩放：拖动四角手柄（按住 Shift 等比缩放）
  • 旋转：将光标放在角外，出现弯箭头后拖动
  • 翻转：右键 → 水平翻转 / 垂直翻转
  • 斜切/扭曲/透视：右键选择对应模式
  • 确认变换：按 Enter

多图层对齐：选中多个图层，在选项栏点击对齐按钮（左对齐、居中、右对齐等）。
